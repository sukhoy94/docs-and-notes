# Section 2: How We Got Here

## Slide 6 — The Evolution of Software Development

**Timeline diagram:**

```
Waterfall → Agile → TDD → BDD → AI-Assisted → ???
 (1970s)   (2001)  (2003) (2006)   (2023)
```

Each era solved the previous era's problem.
But AI created a new gap.

---

## Slide 7 — Waterfall Had Specs

**Waterfall gave us formal specifications.**

But they were:
- Written once, never updated
- Disconnected from code
- Dead on arrival

---

## Slide 8 — Agile Dropped Formal Specs

**"Working software over comprehensive documentation"**

— Agile Manifesto, 2001

User stories replaced specs.
Conversations replaced documents.
Speed replaced formality.

---

## Slide 9 — TDD: Tests as Specs

**Tests define behavior, but not intent.**

> "Testing shows the presence, not the absence of bugs."
>
> — Edsger W. Dijkstra, NATO Conference, 1969

Tests verify *what* the code does.
They don't explain *why* it should do it.

---

## Slide 10 — The Gap

**AI amplified productivity. But deepened the spec gap.**

```
Productivity  ↑↑↑
Clarity       ↓↓↓
```

We can build faster than ever.
But we lost track of *what* we're building.
