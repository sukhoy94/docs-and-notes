# Section 9: Comparisons

## Slide 38 — vs GitHub Spec Kit

| | OpenSpec | Spec Kit |
|---|---------|----------|
| Weight | Lightweight | Heavyweight |
| Workflow | Iterative | Rigid phase gates |
| Setup | `npm install` | Python environment |
| Flexibility | Any AI tool | GitHub ecosystem |

*"Thorough but heavyweight."* — OpenSpec comparison

---

## Slide 39 — vs AWS Kiro

| | OpenSpec | Kiro |
|---|---------|------|
| IDE | Any (36+ tools) | Kiro IDE only |
| Models | Any LLM | Claude models only |
| Approach | Spec-first | IDE-integrated |
| Lock-in | None (MIT) | AWS ecosystem |

*"Powerful but you're locked into their IDE."* — OpenSpec comparison

---

## Slide 40 — vs No Framework

| | OpenSpec | No Framework |
|---|---------|-------------|
| Requirements | Versioned Markdown | Chat history |
| Persistence | Git-tracked specs | Gone when chat closes |
| Review | Human approves artifacts | Hope for the best |
| Consistency | Enforced by specs | Random |

**"Hope is not a strategy."**
